## 理科内容の確認

対象は直流回路・電流・電圧・抵抗・オームの法則。中学理科の電気分野全体（電力・電力量、静電気、磁界・電磁誘導等）を網羅する教材ではない。

| 確認対象 | アプリの条件・結果 | 評価 |
| --- | --- | --- |
| 閉回路・断線 | 1.5 V / 7.5 Ω = 0.20 A。スイッチを開くと0 A | 理想回路の計算として整合 |
| 電流の向き | 電池の外側を＋極から−極へ。粒は電子ではなく模式表現 | 向きを明記。電子の実速度とは区別 |
| 電流計 | 測りたい部分に直列。前後の電流は同じ | 正しい。理想的な抵抗0の計器として扱う |
| 電圧計 | 測りたい部分に並列。電球・電池1.50 V、同じ導線の両端0 V | 正しい。導線の抵抗0、電圧計の電流0が前提 |
| 電流が0のときの電圧 | 開いたスイッチと電池には1.50 V、電球の両端は0 V | 「電流0ならどこも電圧0」ではないことを計算テストで確認 |
| 直列・並列で電球を外す | 直列は全体が消え、並列ではもう一方が点灯を維持 | 電源電圧一定のモデルとして整合 |
| 異なる2負荷の並列 | 3 V、7.5 Ωと15 Ω：0.40 A + 0.20 A = 0.60 A。両負荷の電圧3 V | 電流の和・電圧の等しさを確認 |
| 同じ負荷の直列 | 3 V、7.5 Ωと15 Ω：電流約0.1333 A（表示0.13 A）、電圧1 V + 2 V = 3 V | 丸め前の計算値と表示を区別して確認 |
| オームの法則 | 抵抗器10 Ωで1〜5 Vなら0.10〜0.50 A。3 Vで20 Ωなら0.15 A | 抵抗一定という条件を明記し、単なる式の変形と比例関係を区別 |
| 最終問題の電圧計 | 抵抗器へ直接接続する端子はA・B | 電池端子C・Dでもこの理想回路では同じ値になるため、問いを「直接つなぐ」に限定し、誤答時にも電圧が等しいことを説明 |
| ショート | アプリが通電を停止する | 実物でも自然に安全停止すると誤解しないよう、実際は大電流・発熱があると明記 |

実物の豆電球は温度により抵抗が変わり、明るさは電球の特性にも依存する。ここでの電球は抵抗一定・光の表現は定性的な簡略モデル。比例を調べる課題には抵抗器を使用する。実物計器の極性、レンジ端子・目盛り操作、実際の測定誤差は再現していない。最大測定範囲を選ぶ練習と、実物の全操作を区別する説明へ修正した。
