# MVP検証記録

## 横向きレイアウトへの変更

`npm run test:landscape` により、1280×800、1194×834、844×390、667×375の4サイズで全9ステージを操作。各ステージでページの縦横スクロールが発生せず、数値・操作・次へボタンが画面内に収まることを検証。全サイズ合格、ブラウザエラー0。

電圧・全体の電流を回路の下へ常時表示。短い横向き画面では回路・表とグラフ・操作を横に並べる。説明文・チェックリスト・問題文は学習に必要な内容を残し、重複した見出しや装飾を減らした。結果は `artifacts/landscape-results.json`。

`npm run test:rotation` で縦向きの回転案内、横向きへの切り替え、操作途中の状態保持、縦向き続行、リロード後の復帰を確認。実機の回転・ソフトウェアキーボード・Safariは未検証。

## 実装範囲

ステージ1〜8と、最後の5問の実験問題。以下はローカル環境での検証記録。公開デプロイはGitHub ActionsのPagesワークフローで行う。

## 回路計算

`npm test`: 8件合格。

- 閉回路、開いたスイッチ、断線
- 不均等な抵抗の直列回路：電流の一致と電圧の和
- 並列回路：電流の和と両端の電圧
- 電球を外した場合の直列・並列の違い
- 短絡時の通電停止
- 導線両端の0 Vと開回路でも存在する電池電圧
- 抵抗器の比例関係と抵抗変更
- 各負荷の消費電力と電源の供給電力の一致

## Chromeでの通し操作

実行コマンド: `node tests/browser.mjs`。状態を直接書き換えてステージを飛ばすことはせず、UIのクリック・タップ・数値入力で進行。

| 条件 | 全9ステージ | 問題5問 | ブラウザエラー |
|---|---|---|---|
| PC 1440×1000 / mouse | 合格 | 合格 | 0 |
| タブレット 834×1194 / touch emulation | 合格 | 合格 | 0 |
| スマホ 390×844 / touch emulation | 合格 | 合格 | 0 |

誤接続、短絡、戻す、誤答で進まないこと、全角数字入力、測定値の自動記録、リロード後の再開、前の実験への復帰、再度問題へ戻る動作、動きを減らす設定も検証。

画面キャプチャを目視し、測定線がタップを妨げる問題、二つの電球の重なり、グラフと電圧操作の距離を修正。最終結果は `artifacts/browser-results.json`、各画面は `artifacts/{desktop,tablet,mobile}-*.png`。

## 検証の境界

- Chromeのウィンドウサイズ変更とタッチエミュレーションによる検証。物理的なスマートフォン／タブレットを使用したものではない。
- Safari・Firefoxは未検証。
- 実際の中学生が説明なしで完走できるか、初見問題・後日の問題で理解が定着しているかは未検証。
- 電球は抵抗一定の簡略モデル。計器の極性・レンジ・目盛り、電力・電力量はMVPの対象外。
