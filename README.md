# 電気の流れ — 小さな実験室

中学2年向けの、操作から学ぶ電気教材。ステージ1〜8と、実験文・回路図・測定表・グラフ・計算を結ぶ5問の橋渡し問題を実装しています。

横向きを基本とし、回路・電圧・電流・操作を一画面に表示します。高さの低いスマホでは、表・グラフも横に並べます。縦向きでもそのまま操作できます。回転によって学習状態は失われません。

## 起動

Node.js 20以上。アプリの実行に外部パッケージやAPIキーは不要です。

```sh
npm run dev
```

ブラウザで http://127.0.0.1:4173 を開きます。ローカル専用のサーバーです。

公開URL: https://usapon-jp.github.io/electric-flow/

`npm run build` で公開用の `dist/` を作成します。アセットは相対パスを使うため、サブディレクトリでも動作します。`main` へのpushでGitHub Actionsが計算テスト・ビルドを行い、GitHub Pagesへ配信します。

## 実装範囲

1. 端子を選んで配線、スイッチで点灯
2. 電流の向き、断線、実物と回路記号の対応
3. 電流計を導線の途中へ挿入、前後の電流を比較
4. 電圧計で二点間を測定、電球・電池・導線を比較
5. 直列・並列、電球を外したときの違い
6. 性質の違う二つの負荷で、各部の電流・電圧を測定
7. 抵抗器で電圧を変え、自動記録・表・グラフ・予想
8. 固定電圧で抵抗を比較、オームの法則の計算
9. 接続、プロット、抵抗、未測定の電流、制御条件の5問

前提条件を満たした確認で「次へ」が有効になります。誤答は短い手がかりを出して再試行します。自由配置・無制限の回路編集、ログイン、ランキング、電力・電力量・磁界は対象外です。

## テスト対策ドリル（/drill/）

`drill/index.html` 1ファイルで動く、計算問題のドリルです。公開URL: https://usapon-jp.github.io/electric-flow/drill/

- 単元ごとの問題：ヒントを1段階ずつ出し、途中の計算も入力できる。よくある誤答には個別の手がかりを出す。
- 電流の動き：並列部分がある回路図で、枝ごとの電流の比に合わせて粒が流れる（抵抗値はラベルから読む）。
- 数字をかえて練習：単元ごとに、数字が毎回かわる問題を5問作る（`GEN`）。割り切れない数字は作り直す。
- テスト本番モード：全範囲から10問、答えるまでヒントなし。
- まちがえた問題：単元でまちがえた問題を集め、1回で正解すると外れる。
- テスト前チェック：覚えることのカード。「まだ」のカードをくり返す。

## モデルと注意点

- 導線・電源内部・電流計の抵抗は0。電圧計は回路に負荷を与えません。
- 接続した節点をまとめて節点電位を計算し、電流・電圧・消費電力を表示します。
- 短絡は通電停止として扱います。数値の無限大は表示しません。
- 豆電球は抵抗一定の簡略モデル。明るさは消費電力に対応する定性的な表現であり、実際の温度特性を再現するモデルではありません。
- オームの法則・比例の測定は抵抗器を使用します。
- 光の粒は電流の向きと大きさの模式表現で、電子や物理的な移動速度を表しません。
- 電圧測定は絶対値。最初に最大測定範囲を選ぶ練習はありますが、実物の計器の極性・レンジ端子の切り替え・目盛りの再現はこの版の対象外です。
- 学習状態はローカルストレージに保存します。外部通信・外部フォント・解析サービス・データ送信はありません。
- OSの動きを減らす設定、または「この実験について」の設定でアニメーションを止められます。
- キーボードではTabで端子・計器位置へ移動し、EnterまたはSpaceで操作できます。

## 構成

- `src/physics.js`: 回路計算（表示から独立）
- `src/circuit.js`: SVGによる回路、部品、計器、グラフ
- `src/stages.js`: 学習の内容と初期値
- `src/app.js`: 学習進行、操作、保存、回答判定
- `src/style.css`: レスポンシブUI
- `src/landscape.css`: 横向きの一画面レイアウト・縦向き案内

## 検証

```sh
npm test
npm run build
npm run test:e2e
npm run test:landscape
npm run test:rotation
```

計算テストはNode.js標準のテストランナーを使用します。E2Eは実行中のローカルサーバー、Google Chrome、Playwrightを必要とします。`tests/browser.mjs` はローカルにインストールされたPlaywrightを優先します。別のランタイムを使う場合は、そのpackage.jsonのパスを `PLAYWRIGHT_PACKAGE_ROOT` に指定します。必要なら `npm install --no-save playwright` を実行してください。

E2Eは1440×1000、834×1194、390×844で、配線から最後の問題まで実際のクリック／タップ操作を行います。短絡・誤答・リロード・途中保存・実験への復帰・動きを減らす設定も確認します。結果とスクリーンショットは `artifacts/` に保存されます。

Chromeの画面サイズ・タッチエミュレーションによる検証です。実機のiPhone/iPad/AndroidやSafariでの動作、実際の中学生の学習成果は未検証です。

操作・理科内容の確認記録： [2026-09-20 教材レビュー](docs/lesson-review-2026-09-20.md)。
